# Electronic Shop

## Project Description

Electronic Shop is a full-stack MERN e-commerce application built with TypeScript. It includes authentication, product management, cart & checkout, order handling, reviews, wishlist, admin dashboard, coupon system, and image upload support.

## Features

- User authentication & profile management
- Product browsing, categories, brands & related products
- Shopping cart, wishlist & order system
- Product reviews & ratings
- Admin dashboard with product, order, user & discount management
- Coupon validation system
- Cloudinary image upload support
- Email notifications
- Secure API with JWT, CORS & rate limiting

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- TypeScript
- JWT Authentication
- Cloudinary
- Nodemailer
- Recharts
